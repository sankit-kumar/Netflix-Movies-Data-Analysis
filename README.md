# 🎬 Netflix Movies Data Analysis

## 📌 Project Overview

This project focuses on analyzing a movie dataset using **Python** and popular data analysis and visualization libraries. The objective of this project is to explore movie data, understand different characteristics of movies, and extract meaningful insights from the dataset.

The analysis is performed using **Pandas, NumPy, Matplotlib, and Seaborn** in a Jupyter Notebook.

## 📊 Dataset

The dataset contains **9,827 movie records** and **9 columns**.

### Main Features

* **Release_Date** – Movie release date
* **Title** – Movie title
* **Overview** – Movie description
* **Popularity** – Popularity score of the movie
* **Vote_Count** – Number of votes received
* **Vote_Average** – Average movie rating
* **Original_Language** – Original language of the movie
* **Genre** – Movie genre
* **Poster_Url** – Movie poster URL

## 🚀 How to Run the Project

2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Make sure `mymoviedb.csv` is available in the correct folder.
5. Run the notebook cells sequentially.
